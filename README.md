# Instagram — Intentional Usage

## Overview
A Product Management case study exploring how Instagram can help users reduce doomscrolling and unintended prolonged usage while preserving intentional engagement.

## Problem Statement
Users often open Instagram for a specific purpose but get pulled into Reels and recommended content, spending more time than intended—even after reaching their self-set daily limit.

## Research
- Identified boredom, prolonged scrolling, and lack of control as key pain points.
- Defined **Passive Scrollers & Lurkers** as the primary target segment.

## Proposed Solutions
1. **Persistent Limit Re-entry Check:** Encourage deliberate decisions when users reopen Instagram after reaching their daily limit.
2. **Take a Break:** Prompt users to pause during prolonged scrolling.
3. **Non-Scrollable Shared Reel View:** Let users watch shared Reels without automatically entering an endless feed.

## Prioritization & Metrics
- Used **PIF scoring** to prioritize user problems and compare solutions.
- Defined primary, secondary, and guardrail metrics.
- Proposed an A/B test to measure changes in post-limit reopening and time spent beyond users' self-set limits.

## Deliverables
User research, persona, user journey, problem and solution prioritization, user flows, edge cases, success metrics, A/B testing strategy, and PRD.

## Core Principle
**Interrupt the habit, don't take away the choice.**

The goal is to reduce unintended engagement while preserving meaningful interactions and intentional content consumption.

*Status: Proposed product concept; not validated through a live experiment.*
